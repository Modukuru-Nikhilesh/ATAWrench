# 🔧 ATAWrench

**Fix ATA codes with ATAWrench — drench your brain in aviation maintenance.**

ATAWrench is an aviation maintenance knowledge assistant built for A&P students, junior mechanics, and aviation engineers. It helps users quickly search ATA 100 chapters, identify components, symptoms, manuals, and corrective actions.

## Features

- Search ATA chapters and subchapters
- Aircraft maintenance knowledge base
- Components, symptoms, and corrective actions
- Reference manuals lookup
- Senior Engineer Advisory generation
- Web dashboard for quick troubleshooting

## Tech Stack

- Python
- Flask
- JSON Knowledge Base
- HTML
- CSS
- JavaScript

## Local Run

```bash
pip install flask
python app.py
